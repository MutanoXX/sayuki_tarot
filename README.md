# Sayuki - Site de Tarot

Site completo e responsivo para serviços de tarot com estética gótica dark.

## 📋 Informações

- **Nome Artístico**: Sayuki
- **Especialidade**: Tarot, Sibilla Italiana e Oráculos

## 🎨 Características

- **Tema**: Gótico dark, atmosfera mística e sombria
- **Cores**: Preto predominante com vermelho vinho
- **Animações**: Aranhas, morcegos, velas, névoa e partículas
- **Responsivo**: Mobile-first, funciona em todos os dispositivos

## 📁 Estrutura do Projeto

```
SASA/
├── index.html          # Página principal
├── vercel.json         # Configuração para Vercel
├── css/
│   └── style.css       # Estilos góticos e animações
├── js/
│   └── main.js         # JavaScript e interatividade
├── images/
│   └── sayuki-placeholder.jpg  # Foto placeholder (SUBSTITUIR!)
└── README.md           # Este arquivo
```

## 🖼️ Imagens

### IMAGENS A SEREM SUBSTITUÍDAS:

1. **Foto da Sayuki**
   - Localização: `images/sayuki-placeholder.jpg`
   - Tamanho recomendado: 400x500px ou proporcional
   - Formato: JPG ou PNG
   - Dica: Use uma foto profissional com fundo escuro para combinar com o tema

### COMO SUBSTITUIR AS IMAGENS:

1. Coloque suas fotos reais na pasta `images/`
2. Substitua os arquivos placeholder existentes
3. Certifique-se de usar os mesmos nomes dos arquivos
4. Para melhor qualidade, use fotos com:
   - Boa iluminação
   - Fundo escuro ou transparente
   - Resolução mínima de 800x1000px

## 🚀 Como Usar

### Localmente:

1. Abra o arquivo `index.html` em seu navegador
2. O site funcionará perfeitamente sem servidor local

### Hospedagem no Vercel:

1. Faça upload da pasta SASA para o Vercel
2. Ou use o Vercel CLI:
   ```bash
   cd SASA
   vercel deploy
   ```

3. O arquivo `vercel.json` já está configurado para sites estáticos

## 🎨 Personalização

### Cores:
Edite `css/style.css` e modifique as variáveis CSS no topo:
```css
:root {
  --black: #000000;
  --dark-gray: #0a0a0a;
  --burgundy: #4a0a0a;
  --dark-burgundy: #3a0808;
  --blood-red: #660000;
  --gold: #8b6914;
}
```

### Textos:
Edite `index.html` para modificar textos, títulos e descrições.

### Animações:
Edite `css/style.css` para ajustar velocidades e efeitos.
