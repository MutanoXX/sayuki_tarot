## 🚀 Como Usar

### Localmente:

1. Abra o arquivo `index.html` em seu navegador
2. O site funcionará perfeitamente sem servidor local

### Hospedagem no Vercel:

1. Faça upload da pasta SASA para o Vercel
2. Ou use o Vercel CLI:
   ```bash
   cd SASA
   vercel deploy
   ```

3. O arquivo `vercel.json` já está configurado para sites estáticos
